# 교회 영아부 출석체크 웹서비스

간단한 정적 웹앱으로 다음 기능을 제공합니다.

- **인원관리 화면**: 영아 이름/보호자/생년월일 추가 및 삭제
- **출석체크 화면**: 날짜별 출석 체크박스 관리
- **요약 정보**: 총 인원, 출석 인원, 결석 인원 자동 계산
- **로컬 저장**: 브라우저 `localStorage`에 데이터 저장
- **반응형 UI**: 모바일/태블릿/PC 화면에 맞춰 자동 레이아웃 변경

## 실행 방법

정적 파일 서버로 실행하면 됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 후 `index.html`을 열어 사용하세요.
